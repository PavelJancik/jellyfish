A Python 2D game built with Pygame. Compatible with PS-style controllers.

## Project structure

- `main.py` — entry point
- `engine.py` — main loop and rendering helpers
- `home_screen.py` — title/menu screen
- `game_scene.py` — main gameplay scene
- `map_screen.py` — map view
- `controller_hud.py` — HUD for gamepad
- `interactive_object.py`, `jelly_character.py`, `npc_character.py`, `ambient_fish.py` — game objects
- `subtitle_overlay.py` — subtitle rendering
- `audio/`, `imgs/`, `fonts/` — media assets
